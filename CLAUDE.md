# Твоє право (tvoepravo.org.ua) — контекст для Claude

Навігатор по нормах законодавства України при мобілізації: типові ситуації → що законно, що ні, з посиланнями на статті. Статический сайт (vanilla HTML/CSS/JS, данные в js/data.js), хостится как assets-only Cloudflare Worker.

## Git-процесс (читать первым)

Проект живёт в git — **не создавать копий папок проекта**, вся история версий в git.

- Remote `origin` → https://github.com/stasbabunts-lab/tvoepravo, ветка `main` (репозиторий будет ПУБЛИЧНЫМ — портфолио владельца)
- После каждого законченного изменения: `git add` → `git commit` (осмысленное сообщение на английском) → `git push origin main` → **деплой**
- Секретов в проекте нет и быть не должно; `.wrangler/`, `.env` — в `.gitignore`

## Деплой

**Деплоить сразу после каждого законченного изменения, не спрашивая разрешения.** Изменение считается доделанным только когда оно на проде.

```bash
npx wrangler deploy   # → tvoepravo.org.ua (+ www), zone в Cloudflare
```

После деплоя — быстрая проверка на живом домене (ссылка/блок на месте, консоль чистая), а не только локально.

Откатывать есть куда, поэтому деплой дешёвый: история в git плюс версии воркера в Cloudflare.

```bash
npx wrangler versions list   # 10 последних версий
npx wrangler rollback <version-id>
```

## Локальный просмотр

`.claude/launch.json` → `npx serve -l 4173 .`

Флаг `-s` (SPA-режим) переписывает все пути на `index.html` — страницы из `admin/` так не открыть. Для них поднимать обычный статик-сервер, например `python -m http.server 4174`. API (`/api/*`) локально нет ни там, ни там: он живёт только в воркере на проде.
